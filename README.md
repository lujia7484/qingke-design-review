# 青稞网站设计评审

三个独立的静态网站演示：

1. `motion/`：动态微交互
2. `warm/`：温暖配色版
3. `apple/`：苹果风格版

打开根目录首页即可切换比较。建议从品牌亲和力、信息清晰度、课程查找、预约操作及手机体验五方面反馈。

所有课程、预约、咨询师、活动及 AI 回复均为演示。未接入账号、支付或后台，不包含真实会员信息。Logo 为青稞提供的品牌素材。

## 本地查看

运行 `python -m http.server 8780 --bind 127.0.0.1`，访问 `http://127.0.0.1:8780/`。

## GitHub Pages

在仓库 Settings → Pages 选择从分支发布，分支 main，目录 / (root)。发布完成后使用 GitHub 返回的 Pages 地址。
